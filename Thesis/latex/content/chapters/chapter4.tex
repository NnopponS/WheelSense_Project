\section{ภาพรวมการทดลอง}
\label{sec:ch4_overview}
\noindent
การประเมินผลระบบต้นแบบ WheelSense ในบทนี้จัดทำเพื่อดูว่าองค์ประกอบหลักที่พัฒนาไว้สามารถทำงานร่วมกันได้ในระดับต้นแบบหรือไม่ โดยแบ่งการทดสอบออกเป็นส่วนที่สอดคล้องกับสถาปัตยกรรมในบทที่~\ref{chapter3} ได้แก่ อุปกรณ์ sensor และอุปกรณ์ภาคสนาม การระบุตำแหน่งภายในอาคารด้วย RSSI/KNN การทำงานของ mobile gateway และ server การใช้งาน dashboard/HMI พร้อมการประเมิน SUS และการทดสอบ AI/MCP pipeline ในด้านความสอดคล้องของการเลือกเครื่องมือ ความสม่ำเสมอของคำตอบ และเวลาแฝงของแต่ละ layer

การทดลองทั้งหมดเป็นการทดสอบในพื้นที่ทดลองและสภาพแวดล้อมของโครงงาน ไม่ใช่การนำระบบไปใช้งานจริงในสถานดูแลผู้สูงอายุแบบต่อเนื่อง ดังนั้นผลที่รายงานจึงเป็นผลเพื่อยืนยันความเป็นไปได้ของระบบต้นแบบและเพื่อระบุข้อจำกัดที่ต้องพัฒนาต่อ ไม่ใช่การรับรองความพร้อมใช้งานทางการแพทย์หรือการใช้งานจริงในทุกสภาพแวดล้อม ตารางที่~\ref{tab:ch4_experiment_scope} แสดงขอบเขตการทดลองที่ใช้ในบทนี้

\section{การทดสอบ Indoor Localization ด้วย KNN}
\label{sec:ch4_localization}
\noindent
การทดสอบการระบุตำแหน่งภายในอาคารใช้ข้อมูล RSSI จาก BLE node ในพื้นที่ทดลอง โดย mobile gateway สแกนสัญญาณและส่งรายการ RSSI พร้อม timestamp เข้าสู่ backend เพื่อประเมินตำแหน่งด้วย fingerprint และ KNN ในกรณีที่ fingerprint ยังไม่พร้อมหรือค่าความมั่นใจต่ำ ระบบสามารถใช้ max-RSSI เป็น baseline หรือ fallback ได้

    \label{fig:ch4-user-location}
\end{figure}
