# Realtime Sensor + Polar Live Monitoring UI (Flutter gateway app)

Scope: `mobile-app/wheelsense-gateway-flutter` only. No new packages (Ponytail: reuse existing deps, custom painters stay).

## 1. Centralized rolling history in `GatewayRuntimeService`
Today only `latestM5Sample`/`latestPolarSample` live in the snapshot; screen-local buffers die when you leave the screen. Fix at the source:
- Add bounded ring buffers in `GatewayRuntimeService` (e.g. last 300 samples each, ~same cap PairDevices uses) fed inside `startM5TelemetryRelay` / `startPolarTelemetryRelay` (`lib/services/gateway_runtime_service.dart:190-291`).
- Expose `Stream<List<M5TelemetrySample>> m5History` / `polarHistory` (or include lists in `GatewayRuntimeSnapshot`) so any screen can render history immediately.
- PairDevices switches to consume these instead of its private `_m5Samples`/`_polarSamples`.

## 2. New "Monitor" tab (live dashboard)
Add a 6th destination to `GatewayShell` (`lib/main.dart:180-220`) → new `lib/screens/live_monitor_screen.dart`:
- **Header strip**: connection state for M5 + Polar (from `GatewayRuntimeSnapshot.pairedM5Device/pairedPolarDevice`), publish health (last publish age, failure count), recording indicator.
- **Polar section**: big HR readout with min/max/avg over buffer; HRV (RMSSD) computed from `rrIntervalsMs`; SpO2 estimate numeric tile; contact status + PPG quality badge (currently parsed but never shown); `signalLabel`-based RSSI badge; battery.
- **Motion section**: distance / velocity / acceleration tiles; new Acceleration chart (gyro, velocity, accel all visible); battery level.
- **Empty/disconnected states**: actionable hint ("Pair a device in the Devices tab") instead of blank panels.

## 3. Chart upgrades in `lib/widgets/realtime_charts.dart`
- Add y-axis tick labels + units (bpm, m/s, °/s, g), x-axis time window label, dynamic y-range with sane padding (fix hardcoded HR 40–190 and RSSI null→−100 flat-line bug at `realtime_charts.dart:206-222`).
- Touch/drag readout showing value + timestamp for the traced sample.
- Unified `RealtimeLineChart` widget (series config + painter) to replace the three near-duplicate chart classes; keep existing public names as thin wrappers so PairDevices keeps working.
- Smooth line rendering and subtle gradient fill under the active series.
